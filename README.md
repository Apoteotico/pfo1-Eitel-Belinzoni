# Portfolio Personal — PFO1

Portfolio personal desarrollado como parte del PFO1 de la materia Frontend.

## Descripción

Página web personal desarrollada utilizando HTML5 y CSS3.

El objetivo del proyecto es presentar información personal, habilidades,
intereses y una forma de contacto mediante un formulario.

## Tecnologías utilizadas

- HTML5
- CSS3
- Google Fonts
- Flexbox
- CSS Grid
- Responsive Design

## Características

- HTML semántico.
- Diseño responsive para diferentes tamaños de pantalla.
- Formulario de contacto.
- Enlace al perfil de GitHub.
- Imagen de perfil optimizada para diferentes resoluciones.
- Transiciones CSS.
- Uso de Google Fonts.
- Diseño realizado exclusivamente con HTML y CSS.
